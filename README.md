# Telecom Fuel Operations Dashboard

## Project Overview

This project focuses on analyzing telecom fuel operations using Microsoft Excel.

The dashboard provides insights into fuel filling quantity, technician performance, IE and CMP-wise distribution, daily filling trends, and data mapping issues.

## Tools Used

- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Slicers
- XLOOKUP
- Data Cleaning and Mapping

## Key Features

- Total filling quantity
- Total DFR records
- Technician-wise analysis
- IE-wise and CMP-wise analysis
- Daily filling quantity trend
- Unmapped records identification
- Interactive dashboard filters

## Project Files

### Telecom_Fuel_Operations_Dashboard.xlsx

Contains the interactive dashboard, raw data, cleaned data, master data, and analysis sheets.

### Telecom_Fuel_Operations_Project_Documentation.xlsx

Contains project overview, data cleaning process, data analysis, dashboard KPIs, business value, and project conclusion.

## Business Value

The dashboard improves operational visibility, supports performance monitoring, identifies data mapping issues, and helps in better operational decision-making.
